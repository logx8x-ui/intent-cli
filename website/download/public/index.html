Next, on your Mac

  1. Unzip your download and open Install Intent.command.
  2. Follow Intent’s setup for Accessibility and Screen Recording.
  3. Connect your browser using the instructions inside Intent.

Chrome: enable Developer mode and load the Browser Guard folder that Intent opens for you.

Firefox: load the temporary add-on that Intent opens for you. This tester add-on needs reloading after Firefox restarts.

Already testing? Install this build once to get the automatic updater. Your existing intentions are kept. Future published updates download in the background; finish your intention and restart to apply them.

This preview is not Apple-notarized yet. If macOS blocks it, follow Apple’s instructions for opening a trusted app. Email sign-in is still being verified; you can test as a guest.
